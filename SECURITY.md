| 5.0.x   | ❌                 |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it through GitHub’s **Private Security Advisories**:

➡️ [Create a Security Advisory](../../security/advisories/new)

### What to Expect
- We aim to respond within **5 business days**.  
- If the report is valid, we will:
  1. Confirm the issue.  
    2. Work on a fix.  
      3. Release a patched version and acknowledge your contribution (if desired).  
      - If the report is declined, we will explain why.

      Thank you for helping keep this project secure!
